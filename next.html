多设备协同

跨设备组网，
共用同一个媒体库。

  1. 01

    同一账号自动组网

    台式机、NAS/服务器、电视和手机登录同一个账号后即可建立设备网络，共享媒体库状态。

  2. 02

    移动端远程调用

    iPhone、iPad 和 Apple TV 端不直接运行 Agent，而是将指令转发给组网内已开启梨花的桌面端或服务器执行。

  3. 03

    跨设备投播与读取

    无论文件实际存放在哪台机器上，媒体库视图完全一致，任意终端都可以直接发起播放。

  4. 04

    任务自动分发执行

    多台设备上的梨花可以互相委派任务。例如在电脑上发起需求，由家里长期在线的服务器接管下载，完成后再回传通知。

架构

从能力接口到 Harness，
三层架构拆解。

  1. 01

    能力层（Capabilities）

    NipaPlay 的所有功能都被抽象为标准化能力接口，涵盖播放、检索、下载、元数据、弹幕和设备管理，共 38 类 330 项。GUI 与 Agent 共用同一套能力注册表——界面支持的操作，梨花都可以通过接口调用。

  2. 02

    服务层（Services）

    底层能力由核心服务模块驱动，包括 Erika 播放内核、媒体库、下载器、弹幕引擎、字幕和组网服务。服务层独立于 Agent 运行，后台下载或刮削任务不会因关闭对话窗口而中断。

  3. 03

    智能体与 Harness

    梨花默认运行在 DeepSeek Harness 上，也支持切换至 Codex 或接入你自己的模型 API。她的提示词约束、记忆文件、自定义工具和事件钩子全部存放在最底层的 Git Harness 仓库中。

  1. 01

    AGENTS.md：角色与行为边界

    定义梨花的工作职责、操作规范以及需要向用户二次确认的边界条件。每次执行任务前都会优先加载这份配置。

  2. 02

    memory/：持久化记忆与偏好

    记录你的观影偏好、脚本调用经验以及单部作品的备注信息，每条记忆均附带日期与来源；使用前会核对当前状态，敏感凭据（如密码、Token）不会写入记忆。

  3. 03

    tools/ 与 hooks/：可扩展脚本与钩子

    tools/ 存放用于搜刮资源、获取弹幕、查询接口的脚本，梨花可以根据实际需求修改或新建工具；hooks/ 中的脚本则会在开始播放、下载完成等生命周期事件触发时自动执行。

  4. 04

    完整的 Git 版本历史

    梨花对配置、记忆和脚本的每一次改动都会生成一条 Git 提交记录。改了什么、为什么改全程可审计，不满意随时 revert。
